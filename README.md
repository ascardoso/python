# python
Helpful scripts in Python (made via chatGPT)

WebViewerEditor2.py reads a bookmark.html file, dedupes entries. Allows for check validation (404) and removal of those sites, plus json file saving state

FileViewer4.py Asks for a folder to be opened/selected, then lists all files on its left pane, selecting one will display its contents. Supports .txt, .rtf, .rtfd, .png, .jpg and other text and image files
