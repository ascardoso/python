# python
Helpful scripts in Python

WebViewerEditor2.py readers a bookmark.html file, dedupes entries. Also allows for check validation (404) and allows for removal of those sites, plus json file saving their state

FileViewer4.py Asks for a folder to be opened/selected, then lists all files on its left pane, selecting one will display its contents. Supports .txt, .rtf, .rtfd, .png, .jpg and other image files
