## **Lissajous Playground**

First prototype ready

Two oscillators, an interactive XY oscilloscope, and live audio.

&#x20; Open / download HTMLStandalone HTML — no installation or server required.

### **What's inside**

- **Phase slider:** smoothly morphs the figure from 0° to 360°.
- **Two frequency controls:** independently change X and Y.
- **Ratio presets:** 1:1, 1:2, 2:3, 3:4, and more.
- **Live audio:** hear both oscillators together.
- **XY oscilloscope:** watch the geometry evolve.
- **Individual waveforms:** see the two signals responsible for the shape.
- **Drawing speed:** slow down the visual trace without changing audio pitch.

One particularly important detail: the audio phase adjustment uses two quadrature components, so dragging the phase slider changes the actual oscillator relationship, not just the drawing.

### **Try this first**

1. Start the sound.
2. Select 1:1.
3. Slowly drag phase from 0° to 360°.
4. Try 2:3.
5. Keep moving the phase slider.

Notice how the geometry changes even though the frequencies haven't changed.

**That's the magic of phase.** Two oscillators, same frequencies, different relationships—and an entirely different picture. 🎛️
